# Xanaan Love QR Project

Bogga hore (index.html) weli waa yaallaa.
Hadiyadda cusub waxay ku furantaa PHP + MySQL.

Sida loo bilaabo:
1. XAMPP MySQL ha socdo.
2. Laba-jeer taabo start-server.bat.
3. Kombayutarka ku fur: http://127.0.0.1:8080/admin/
4. Magaca gelitaanka wuxuu ku qoran yahay storage/owner-access.txt
5. Samee hadiyad, kadibna soo deji QR-ka.

Telefoonka:
- Kombayutarka iyo telefoonka ha isku Wi-Fi ahaadaan.
- Gal admin-ka adigoo isticmaalaya cinwaanka Wi-Fi ee kombayutarka, tusaale http://192.168.1.20:8080/admin/
- Kadib soo deji QR-ka. Haddii QR-ku yahay 127.0.0.1, telefoonku ma furi karo.

Tusaale diyaar ah:
http://127.0.0.1:8080/surprise/XANAAN

Hadiyad kasta waxay leedahay link gaar ah: /surprise/CODE
Qofka scan-gareeya wuxuu arkaa oo keliya hadiyadda QR-kaas.
